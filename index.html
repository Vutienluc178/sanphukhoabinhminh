Hướng Dẫn Đồng Bộ Google Sheets

Làm theo 5 bước dưới đây để dữ liệu tự động ghi lên Google Sheets

Cơ chế hoạt động

GynoFlow → Google Apps Script → Google Sheets. Mỗi khi lập hóa đơn, chấm công hoặc phiếu chi, app tự động gửi dữ liệu đến Google Sheets qua HTTPS.

1

Tạo Google Sheets mới

Truy cập sheets.google.com → Tạo bảng tính mới.

Tạo 5 sheet (tab) với tên chính xác như sau:

HoaDon

Lưu hóa đơn

ChamCong

Chấm công

PhieuChi

Mẹo: Sheet DichVu và Thuoc dùng để app tải danh mục. Cột A = ID, Cột B = Tên, Cột C = Giá, Cột D = Đơn vị (chỉ Thuoc).

📋 Sao chép Spreadsheet ID từ URL: docs.google.com/spreadsheets/d/[COPY PHẦN NÀY]/edit

2

Mở Apps Script Editor

Trong Google Sheets: click menu Tiện ích mở rộng → Apps Script

Một tab mới mở ra — đây là nơi viết code để nhận dữ liệu từ GynoFlow.

Xóa hết code mẫu trong editor, dán đoạn code ở Bước 3 vào.
3

Dán code Apps Script

Copy toàn bộ đoạn code bên dưới và dán vào Apps Script Editor:

// GynoFlow Apps Script v2 — 2 chiều (doGet + doPost)
// Dán toàn bộ vào Apps Script Editor → Deploy → Web App → Anyone

function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const now = new Date().toLocaleString('vi-VN');

    // ── SYNC: lưu snapshot toàn bộ DB ──────────────────
    if (data.action === 'syncAll') {
      const sh = ss.getSheetByName('SYNC') || ss.insertSheet('SYNC');
      sh.clearContents();
      const keys = ['patientDB','appointments','invoiceHistory','expenses','CATALOG'];
      sh.getRange('A1').setValue('lastSync');
      sh.getRange('B1').setValue(now);
      keys.forEach(function(k, i) {
        sh.getRange('A' + (i+2)).setValue(k);
        sh.getRange('B' + (i+2)).setValue(JSON.stringify(data[k] !== undefined ? data[k] : null));
      });
      return _json({status:'ok', synced: now});
    }

    // ── LOG: ghi sổ hóa đơn / chi phí / ca làm ────────
    if (data.action === 'invoice') {
      const sh = ss.getSheetByName('HoaDon') || ss.insertSheet('HoaDon');
      sh.appendRow([data.timestamp, data.patientId, data.patientName,
        data.patientYob, data.patientPhone, data.totalAmount, data.details, now]);
    }
    if (data.action === 'expense') {
      const sh = ss.getSheetByName('PhieuChi') || ss.insertSheet('PhieuChi');
      sh.appendRow([data.dateStr, data.expId, data.amount,
        data.category, data.reason, data.staffName, now]);
    }
    if (data.action === 'attendance') {
      const sh = ss.getSheetByName('ChamCong') || ss.insertSheet('ChamCong');
      sh.appendRow([data.dateStr, data.timeStr, data.staffName, data.shift, now]);
    }
    if (data.action === 'close_shift') {
      const sh = ss.getSheetByName('ChamCong') || ss.insertSheet('ChamCong');
      sh.appendRow([data.dateStr, 'CHOT_CA', data.staffName, data.shift,
        data.expected, data.actual, data.variance, data.note, now]);
    }
    if (data.action === 'void') {
      const sh = ss.getSheetByName('HoaDon') || ss.insertSheet('HoaDon');
      sh.appendRow([data.dateStr, 'HUY', data.patientName, '', '', 0,
        'HUY ' + data.invId + ': ' + data.reason, data.staffName, now]);
    }

    return _json({status:'ok'});
  } catch(err) {
    return _json({status:'error', message: err.toString()});
  }
}

// ── doGet: trả về snapshot mới nhất ───────────────────
function doGet(e) {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const sh = ss.getSheetByName('SYNC');
    if (!sh) return _json({status:'ok', empty:true, data:{}});

    const rows = sh.getDataRange().getValues();
    const result = {};
    rows.forEach(function(row) {
      const key = row[0], val = row[1];
      if (key && key !== 'lastSync' && val) {
        try { result[key] = JSON.parse(val); } catch(e) { result[key] = val; }
      }
    });
    const lastSync = rows.length > 0 ? rows[0][1] : '';
    return _json({status:'ok', data: result, lastSync: lastSync});
  } catch(err) {
    return _json({status:'error', message: err.toString()});
  }
}

function _json(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

Deploy Web App

a

Trong Apps Script Editor: click nút Deploy (góc trên phải) → New deployment

b

Click biểu tượng ⚙️ → chọn loại Web app

c

Cấu hình như sau:

Execute as: Me (your email)

Who has access: Anyone ← Quan trọng!

d

Click Deploy → Cấp quyền nếu được hỏi → Copy Web app URL

Lưu ý: Mỗi lần sửa code phải Deploy → New deployment lại và lấy URL mới. URL cũ sẽ chạy code cũ.

Câu Hỏi Thường Gặp

Bấm Test nhưng báo lỗi?

Kiểm tra lại: (1) URL đúng định dạng https://script.google.com/macros/s/.../exec, (2) Đã chọn Anyone khi Deploy, (3) Đã cấp quyền cho script khi được hỏi.

Dữ liệu ghi được nhưng DichVu/Thuoc không load?

Sheet danh mục được đọc trực tiếp từ Spreadsheet ID (không qua Apps Script). Đảm bảo: (1) Tên sheet chính xác khớp trong Cài Đặt, (2) Google Sheet được chia sẻ Anyone with the link can view.

Mỗi lần mở app phải đồng bộ lại?

App tự đồng bộ danh mục khi đăng nhập ca. Dữ liệu hóa đơn, bệnh nhân, lịch hẹn lưu trên máy (localStorage). Bấm Đồng bộ dữ liệu mới trong sidebar nếu bạn vừa cập nhật danh mục trên Sheet.

Dùng nhiều máy tính, dữ liệu có sync không?

Hiện tại dữ liệu bệnh nhân và lịch hẹn lưu trên từng máy riêng. Hóa đơn, chấm công, phiếu chi ghi lên Google Sheets từ tất cả máy. Để sync hoàn toàn cần nâng cấp lên backend (Firebase/Supabase) — liên hệ dev để hỗ trợ.
